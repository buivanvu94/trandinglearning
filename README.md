# Trading Masterclass Pro — User Management & Learning System

Dự án hoàn chỉnh gồm:
1. **Module Quản trị Học viên & Phân quyền (RBAC):** Đăng ký ➔ Chờ phê duyệt (Pending) ➔ Admin 1-Click Kích hoạt ➔ Đăng nhập.
2. **Module Quản lý Bài học & Import ZIP:** Tải lên file ZIP hình ảnh, tự động nhận diện tên bài học, sắp xếp slide và lưu vào MySQL.
3. **Cơ sở dữ liệu MySQL:** Cấu hình qua `.env`, tự động tạo bảng và nạp dữ liệu khởi tạo.
4. **Giao diện chuẩn Apple Pro & Impeccable Design:** Tinh tế, sắc nét, hỗ trợ bài giảng 2K chuyên nghiệp.

👉 **Chi tiết hướng dẫn và mã nguồn:** Xem tại thư mục [`trading-viewer/`](./trading-viewer/).

### Khởi chạy nhanh
```bash
cd trading-viewer
start.bat
```
